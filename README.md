# HF Downloader

Hugging Face model, dataset ve Bucket içeriklerini bilgisayara indirmek için Electron masaüstü uygulaması.

## Kullanım

```bash
npm install
npm start
```

Bucket desteği için sistemde Hugging Face CLI bulunmalıdır:

```bash
pip install -U huggingface_hub
```

## Build

```bash
npm run dist
```
